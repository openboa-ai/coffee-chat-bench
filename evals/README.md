# Evaluation definitions

This directory separates output-quality evaluation from Skill triggering.
perspective-capture measures Roast's Origin-to-Bean capture effect.
perspective-application measures Brew's Bean-to-Coffee effect for Human
Understanding and Agent Judgment / Action.

The same case is executed in paired with-skill and without-skill arms by
coffee-chat-eval. This repository defines the case and its expected outcomes;
it does not run an agent or retain generated outputs.

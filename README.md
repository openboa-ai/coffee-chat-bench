# coffee-chat-bench

Independent benchmark cases and ground-truth criteria for Coffee Chat.

`coffee-chat-bench` owns the independent evaluation cases, ground-truth expectations, semantic criteria, and grader qualification definitions for the [Coffee Chat](https://github.com/openboa-ai/coffee-chat) repository family.

## Status

This repository currently holds the verified CI and security baseline while benchmark specifications and case fixtures are prepared. CI checks workflow syntax, whitespace, and secrets; these checks do not validate product behavior, and no deployment credentials or release pipeline are configured here.
